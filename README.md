# Project Form Frontend (Projektni Obrazec)

A specialized web interface for creating detailed "living specifications" for job positions and organizational requirements.

## 📋 Overview
This application serves as the primary data entry point for defining complex project parameters. It allows administrators to build structured forms that define salary brackets, required candidate skills, and legal benefits, which later drive automated logic in the mobile application.

## 🛠 Tech Stack
* **Framework:** Vite
* **Language:** TypeScript
* **Rich Text Editor:** TinyMCE
* **Styling:** Bootstrap

## ✨ Key Features
* **Dynamic JSONB Structures:** Uses a flexible data model to handle nested requirements and complex form logic without database schema changes.
* **Integrated Document Preview:** Built-in iframe viewer for managing and reviewing files stored in the cloud.
* **Specialized Logic Modules:** Custom inputs for complex data types like mileage reimbursement, medical restrictions, and multi-currency salary definitions.
